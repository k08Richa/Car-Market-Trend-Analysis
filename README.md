# Car Market Trends Analysis - CarDekho Dataset

## Overview
Exploratory data analysis of 299 used car listings from CarDekho, 
completed as part of the VOIS for Tech Data Analytics Program.

## Objective
Identify key factors influencing used car resale price and depreciation 
across fuel type, transmission type, car age, and kilometres driven.

## Tools Used
- Python (pandas, numpy, matplotlib, seaborn)
- Google Colab

## Key Findings
- Diesel cars command 3x higher average resale value than Petrol (₹10.10L vs ₹3.26L)
- Automatic transmission cars sell for more than double Manual cars
- CNG vehicles depreciate fastest at ~ 49% average
- Car age beyond 12 years significantly reduces resale price
